# Multiphase extension area

This directory has no runnable case yet. Begin with a matching official v2606
multiphase tutorial (for example, an appropriate `interFoam` VOF case).
Phase fractions, phase properties, surface tension, gravity, initialization
such as `setFields`, and interface/Courant controls must be consistent.
The starter pipeline does not perform those extra steps; preserve the
tutorial's Allrun until you explicitly integrate them.
