# Compressible-flow extension area

This directory has no runnable case yet. Use a complete official v2606
`rhoSimpleFoam` or `rhoPimpleFoam` tutorial suited to your thermodynamics,
Mach number, and boundary conditions. Compressible pressure is normally in
Pa, and temperature/energy plus thermophysical properties are required.
Do not select an incompressible template and only change its solver name.
See `templates/README.md` for extending the launcher and pipeline.
