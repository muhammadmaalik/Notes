# Active Simulation Cases (cases/)

Working directory for active runs. Everything inside cases/ (except .gitkeep and README.md) is ignored by Git.
Preserved working cases live here. Create new CAD runs with `new_run.cpp` in the
workspace root; its independent folders go under `runs/`.
For an optional manual reference case, copy its template into a fresh directory
here. Edit working copies rather than the reference templates.
